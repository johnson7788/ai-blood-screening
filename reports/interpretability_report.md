# 可解释性分析报告：EBM 形状函数 + Morris 全局敏感性 + SHAP 交叉验证

> 数据：NHANES 4 周期 41,333 人｜训练队列 2013-2016
> 被分析模型：EBM（Explainable Boosting Machine）
> 运行日期：2026-10-13｜固定随机种子 42

---

## 一、为什么要做三种方法

单一的可解释性方法都有盲区，三者互补：

| 方法 | 度量的是什么 | 优势 | 盲区 |
|---|---|---|---|
| **EBM 形状函数** | 模型内部各特征的**加性贡献曲线** | 与模型真实结构严格一致，可画曲线 | 只反映该模型自身的函数形式 |
| **SHAP** | 每个样本上各特征对预测的**边际贡献** | 有严格的博弈论基础，支持局部解释 | 对黑盒是近似，特征相关时会失真 |
| **Morris** | 模型输出对输入**扰动的敏感度** | **不依赖模型内部结构**，纯黑盒可用；额外给出交互强度 σ | 独立扰动特征，会触及现实罕见的组合 |

**三者一致 → 结论稳健；三者分歧 → 说明信号本身不稳定。** 这正是本次分析最有价值的用法。

## 二、Morris 全局敏感性分析

### 2.1 方法

Morris 通过生成多条「一次一个变量」（OAT）轨迹估计**基本效应**：

```
EE_i = [ f(x + Δ·e_i) − f(x) ] / Δ
```

跨轨迹汇总得到三个指标：

| 指标 | 含义 |
|---|---|
| **μ\*** | 平均绝对基本效应 —— **重要性**（不受正负抵消影响） |
| **μ** | 基本效应均值 —— **作用方向**（正=推高风险） |
| **σ** | 基本效应标准差 —— **非线性与交互作用强度** |

**经典 μ\*-σ 解读**：

- μ\* 大、σ 小 → 重要且近似线性可加
- μ\* 大、σ 大 → 重要但**高度依赖其他变量**（交互）
- μ\* 小 → 不重要

### 2.2 配置

| 项 | 取值 |
|---|---|
| 轨迹数 r | 20 |
| 网格层数 | 4 |
| 取值边界 | 各特征 1–99 百分位（避免外推到极端区域） |
| 模型评估次数 | (33+1) × 20 = **680 次/病种** |
| 重采样 | 200 次，置信水平 95% |

### 2.3 各病种 μ\* Top 8

| 病种 | Top 特征（μ\*） |
|---|---|
| **高血压** | 年龄 0.660 · BMI 0.243 · 肌酐 0.186 · 钾 0.118 · 尿素氮 0.109 · 钙 0.103 |
| **糖尿病** | 年龄 0.446 · BMI 0.236 · 甘油三酯 0.185 · 钠 0.164 · 钙 0.155 · 总胆固醇 0.154 |
| **癌症** | 年龄 0.218 · 单核细胞% 0.043 · BMI 0.042 · MCV 0.036 · 淋巴细胞% 0.023 |
| **冠心病** | 年龄 0.194 · 总胆固醇 0.067 · 尿酸 0.061 · 淋巴细胞% 0.039 · 钾 0.039 |
| **心梗** | 年龄 0.344 · 总胆固醇 0.123 · RDW 0.080 · 甘油三酯 0.079 · 尿素氮 0.064 |
| **中风** | 年龄 0.214 · 尿酸 0.103 · RDW 0.085 · 甘油三酯 0.083 · ALT 0.079 |
| **慢性肾病** | 年龄 0.212 · **钾 0.204** · 血红蛋白 0.136 · RDW 0.125 · MCHC 0.123 |

**两点观察**：

1. **年龄在全部 7 个病种中都是 μ\* 第一**，且量级往往是第二名的 2–3 倍——与 SHAP、EBM 的结论完全一致。
2. **慢性肾病是唯一「年龄未断层领先」的病种**（0.212 vs 钾 0.204），其信号以**电解质与红细胞形态学**（钾、血红蛋白、RDW、MCHC、红细胞压积）为主——符合肾性贫血与电解质紊乱的病理。

### 2.4 交互作用维度（Morris 独有）

σ/μ\* 比值高 = 该特征的效应**强烈依赖其他变量的取值**：

| 病种 | 强交互特征 |
|---|---|
| 高血压 | 中性粒细胞% (1.59) · 总胆固醇 (1.50) · MCH (1.46) |
| 糖尿病 | 血小板 (1.50) · 钠 (1.06) · 白蛋白 (0.99) |
| **癌症** | **钠 (2.27) · BMI (2.11) · 淋巴细胞% (1.93)** |
| 冠心病 | 尿酸 (2.22) · 钾 (2.07) · 血小板 (1.74) |
| 心梗 | 血小板 (1.61) · 血红蛋白 (1.53) · 糖化血红蛋白 (1.43) |
| 中风 | AST (1.97) · 红细胞压积 (1.91) · ALT (1.75) |
| 慢性肾病 | 单核细胞% (1.65) · AST (1.55) · 红细胞压积 (1.38) |

**癌症的 σ/μ\* 比值普遍在 2 左右**，说明其风险因素的作用**高度条件化**（取决于其他指标的组合），而非简单的线性叠加。这与癌症 AUC 仅 0.78、本质是异质性疾病集合的事实一致。

> **实践含义**：σ 大的特征不适合用「单一阈值」做临床解读，需要结合其他指标看。这也解释了为什么 EBM 在癌症上自动学出了「年龄×性别」「红细胞×年龄」等交互项。

## 三、三方交叉验证

### 3.1 重要性排序一致性（Spearman ρ）

| 病种 | Morris~EBM | Morris~SHAP | EBM~SHAP |
|---|---|---|---|
| 糖尿病 | **0.838** | **0.797** | **0.922** |
| 心梗 | 0.741 | 0.668 | 0.696 |
| 高血压 | 0.665 | 0.661 | **0.894** |
| 慢性肾病 | 0.621 | 0.546 | 0.862 |
| 癌症 | 0.566 | 0.448 | 0.397 |
| 冠心病 | 0.517 | 0.635 | 0.593 |
| **中风** | **0.304** | **0.085** | **0.372** |
| **平均** | **0.607** | **0.549** | **0.677** |

### 3.2 关键发现：方法分歧本身是诊断信号

**中风的三方一致性最低**（Morris~SHAP 仅 0.085，几乎不相关）。这不是方法出错，而是**该病种的预测信号本身弱且不稳定**——三种独立方法各自抓到了不同的噪声，自然无法收敛。

对照中风的实际表现：外部验证 AUC **0.7647，7 个病种中最差**。**方法分歧与实际性能完全对应。**

反过来，**糖尿病三方一致性最高**（0.84/0.80/0.92），其外部 AUC 也最高（0.8856）。

> **可操作的结论**：可以把「三方一致性」当作一个**无需额外验证数据的信号质量指标**。在实际项目上，对一致性低的病种应降低预期，或优先补充特征/样本。

### 3.3 同时进入三方 Top5 的特征（高置信度）

| 病种 | 三方一致的核心特征 |
|---|---|
| 高血压 | 年龄 · BMI · 肌酐 |
| 糖尿病 | 年龄 · BMI · 钙 · 甘油三酯 |
| 癌症 | 年龄 · 淋巴细胞% · 单核细胞% |
| 冠心病 | 年龄 |
| 心梗 | 年龄 · RDW · 总胆固醇 |
| 中风 | 年龄 · RDW |
| 慢性肾病 | 年龄 · 钾 |

**汇总**：`年龄` 7/7 全部一致；`RDW`（红细胞分布宽度）在 3 个心脑血管病种中一致；`淋巴细胞%`/`单核细胞%` 在癌症中一致——再次印证**血常规分类计数与红细胞参数是跨病种的核心信号**。

## 四、方法的适用边界（必须说明）

1. **Morris 度量的是「模型敏感性」，不是因果效应。** 本项目的特征是真实数据中彼此相关的，而 Morris 独立扰动各变量，会产生真实人群中罕见的组合。结论应解读为「模型如何响应」，而非「干预该指标会如何改变风险」。

2. **Morris 的 σ 只是交互作用的「指示」，不指明与谁交互。** 想定位具体交互对，需要 Sobol 指数或 EBM 的成对交互项（后者已在 `reports/ebm_importance_*.csv` 中以 `type=交互项` 标出）。

3. **EBM 的形状函数只对该模型成立。** 换模型后形状会变，这也是为什么需要 Morris 这种模型无关的方法做交叉验证。

4. **三种方法都不能替代前瞻性验证。** 重要性排序说明模型在看什么，不说明模型是否正确。

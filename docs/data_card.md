# 数据集卡片 — `nhanes_wide.parquet`

## 基本信息

| 项 | 值 |
|---|---|
| 文件名 | `nhanes_wide.parquet` |
| 形状 | 41,333 行 × 55 列 |
| 体积 | 2.1 MB（另有 CSV 格式 8.6 MB，可由 `build_dataset.py` 重新生成） |
| 行单位 | 一位 NHANES 参与者（一个调查周期内） |
| 主键 | `SEQN`（NHANES 受访者序号） |
| 数据来源 | 美国 CDC NHANES 公开数据文件（公共领域） |
| 生成方式 | `build_dataset.py` 按 `SEQN` 外连接 71 个原始模块文件 |
| 覆盖周期 | 2013-2014 / 2015-2016 / 2017-2018 / 2021-2023 |

## 用途

用于复现「常规血液检验 → 多病种筛查」的堆叠集成方法。可作为：
- 血检特征工程与建模的教学/基准数据集
- 标签泄漏问题的实证案例（含同源诊断变量）
- 复杂抽样加权方法的练习数据

## 重要说明：缺失是结构性的

**本数据集的缺失不是条目漏检，而是 NHANES 的抽样设计造成的**：

| 模块 | 覆盖率 | 缺失原因 |
|---|---|---|
| 血常规 | 63.6% ~ 84.0% | 仅在体检（MEC）子样本中检测 |
| 生化全套 | 53.0% ~ 64.4% | 仅在更小的生化子样本中检测 |
| 空腹血糖/胰岛素/甘油三酯/LDL | 29.3% ~ 30.7% | 仅 1/3 空腹子样本 |
| C 反应蛋白 | 54.2%（2013-2014 为 0%） | 该周期未检测 |

⚠️ **因此不要按变量缺失率直接删列**——这会删掉几乎全部血液指标。
本包的做法是在**样本层面**取完整案例（CBC + 生化 + 人口学齐全 = 24,460 人）。

加权时：血常规/生化用 `WTMEC2YR`，空腹子样本需改用 `WTSAF2YR`（原始文件中有）。

## 已知的标签泄漏风险

**使用本数据集建模时，务必剔除与目标疾病同源诊断的变量**，否则性能会严重虚高：

| 目标疾病 | 必须剔除 |
|---|---|
| 糖尿病 | `LBXSGL`、`LBXGLU`、`LBXGH`、`LBXIN` |
| 慢性肾病 | `LBXSCR`、`LBXSBU`、`LBXSUA` |
| 高血压 / 冠心病 / 心梗 / 中风 / 癌症 | 无（诊断不依赖血液指标） |

实测影响：糖尿病 AUC 虚高 **+0.0708**、慢性肾病虚高 **+0.0428**。
完整对照表见 `reports/leakage_table.csv`，实现见 `src/variables.py` 的 `LEAKAGE_EXCLUSIONS`。

## 局限

1. 标签为自报，存在未诊断偏倚
2. 横断面数据，无纵向随访，不支持时序建模
3. 无凝血项（PT%、纤维蛋白原）
4. 仅覆盖美国人群
5. 空腹子样本仅约 30%，计算 HOMA-IR 等指标时样本量会大幅缩小
